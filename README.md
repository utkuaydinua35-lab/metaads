# metaads

Meta Marketing API için bağımlılıksız Python CLI.

## Kurulum
    ln -s "$PWD/metaads.py" ~/bin/metaads
    echo 'META_TOKEN=...' > ~/.metaads.env && chmod 600 ~/.metaads.env
    metaads accounts
    metaads use act_XXXX

## Komutlar
accounts, use, campaigns, adsets, ads, insights, pause, activate, budget, rename, copy, raw

`metaads <komut> --help` ile detay.
